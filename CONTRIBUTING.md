# Reporting a bug

Use the repository's Bug Report form. Include the launcher version, Windows version, Minecraft and loader versions, steps to reproduce the problem, and the relevant error message.

Before attaching a log or screenshot, remove account names, email addresses, authentication tokens, personal file paths, and other private information. Never attach passwords or credentials.

This public repository distributes the finished Nexus Launcher binaries and release materials. It does not accept source-code contributions to the proprietary product.
